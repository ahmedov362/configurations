## 🗂️ Шпаргалка по файл-менеджеру Yazi (`yazi`)

## 🧭 Навигация
| Клавиша | Что делает |
|---------|-----------|
| `h` / `l` | Выйти / войти в папку |
| `j` / `k` | Вниз / вверх |
| `g g` | В начало списка |
| `G` | В конец списка |
| `H` | Назад (история) |
| `L` | Вперёд (история) |
| `~` | Домашняя папка |
| `-` | Предыдущая папка |

## 📋 Выделение
| Клавиша | Что делает |
|---------|-----------|
| `Space` | Выделить/снять файл |
| `v` | Visual mode (выделение диапазона) |
| `V` | Инвертировать выделение |
| `Esc` | Снять всё выделение |

## 📁 Операции с файлами
| Клавиша | Что делает |
|---------|-----------|
| `y` | Копировать (yank) |
| `x` | Вырезать |
| `p` | Вставить |
| `P` | Вставить (перезаписать) |
| `d` | Удалить в корзину |
| `D` | Удалить навсегда |
| `r` | Переименовать |
| `a` | Создать файл/папку (папка — с `/` в конце) |

## 🔍 Поиск / Фильтр
| Клавиша | Что делает |
|---------|-----------|
| `/` | Поиск по имени (вниз) |
| `?` | Поиск по имени (вверх) |
| `n` / `N` | Следующее / предыдущее совпадение |
| `f` | Фильтр (показывает только совпадения) |
| `F` | Умный поиск (fd) |
| `s` | Поиск через fd в текущей папке |
| `S` | Поиск через fd с нуля |

## 👁️ Просмотр
| Клавиша | Что делает |
|---------|-----------|
| `Enter` / `o` | Открыть файл |
| `O` | Открыть в другой программе |
| `i` | Предпросмотр во весь экран |
| `Tab` | Показать/скрыть превью |

## 📑 Вкладки
| Клавиша | Что делает |
|---------|-----------|
| `t` | Новая вкладка |
| `[` / `]` | Предыдущая / следующая вкладка |
| `1-9` | Перейти на вкладку N |
| `W` | Закрыть вкладку |

## ⚡ Разное
| Клавиша | Что делает |
|---------|-----------|
| `q` | Выйти |
| `Q` | Выйти + cd в текущую папку |
| `.` | Показать скрытые файлы |
| `z` | Прыгнуть через zoxide |
| `Z` | Перейти через fzf |
| `c m` | chmod (права доступа) |
| `!` | Открыть shell в текущей папке |
| `w` | Показать задачи (Tasks) |
| `?` | Показать все хоткеи |

## 📝 LazyVim (Neovim)

### 🧭 Навигация

| Клавиша | Что делает |
|---------|-----------|
| `h j k l` | ← ↓ ↑ → |
| `w` / `b` | Слово вперёд / назад |
| `e` | Конец слова |
| `0` / `$` | Начало / конец строки |

| `{ }` | Абзац вверх / вниз |

| `%` | Парная скобка |

## ⚙️ Конфигурации окружения (Noctalia / Niri Setup)

Мой кастомный сетап на базе горизонтального Wayland-композитора **Niri** и графической оболочки **Noctalia Shell v4.7.7**.

* 💻 **Терминал:** [Kitty Configuration](./kitty/kitty.conf) — графическое ускорение, кастомные шрифты Outfit.
* 🌀 **Композитор:** [Niri Configuration](./niri/config.kdl) — бесконечная горизонтальная лента, маппинги окон.

# 🐧 My Fedora + niri config

## Setup
- **Distro:** Fedora Linux 44
- **WM:** niri (Wayland)
- **Shell:** fish
- **Terminal:** kitty
- **Panel:** Noctalia (Quickshell)
- **Colors:** wallust (auto-sync с обоями)

## Что внутри
- `niri/` — конфиг WM
- `rofi/` — тема + скрипты (wiki, calc, translate, switch раскладки)
- `wallust/` — шаблоны для авто-темизации
- `scripts/theme.py` — синхронизация цветов kitty/niri

## Автосинк цветов
Хук Noctalia → wallust → все приложения перекрашиваются при смене обоев.
