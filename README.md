# 🛠️ SynByte Dotfiles & CheatSheets

Добро пожаловать в мой личный репозиторий конфигураций и шпаргалок. Здесь собрано всё, что я использую в своих видео на YouTube для автоматизации, кастомизации Linux и оптимизации систем.

---

## 🗂️ Шпаргалка по файл-менеджеру Yazi (`yazi`)

## 🧭 Навигация
| Клавиша | Что делает |
|---------|-----------|
| `h` / `l` | Выйти / войти в папку |
| `j` / `k` | Вниз / вверх |
| `g g` | В начало списка |
| `G` | В конец списка |
| `H` | Назад (история) |
| `L` | Вперёд (история) |
| `~` | Домашняя папка |
| `-` | Предыдущая папка |

## 📋 Выделение
| Клавиша | Что делает |
|---------|-----------|
| `Space` | Выделить/снять файл |
| `v` | Visual mode (выделение диапазона) |
| `V` | Инвертировать выделение |
| `Esc` | Снять всё выделение |

## 📁 Операции с файлами
| Клавиша | Что делает |
|---------|-----------|
| `y` | Копировать (yank) |
| `x` | Вырезать |
| `p` | Вставить |
| `P` | Вставить (перезаписать) |
| `d` | Удалить в корзину |
| `D` | Удалить навсегда |
| `r` | Переименовать |
| `a` | Создать файл/папку (папка — с `/` в конце) |

## 🔍 Поиск / Фильтр
| Клавиша | Что делает |
|---------|-----------|
| `/` | Поиск по имени (вниз) |
| `?` | Поиск по имени (вверх) |
| `n` / `N` | Следующее / предыдущее совпадение |
| `f` | Фильтр (показывает только совпадения) |
| `F` | Умный поиск (fd) |
| `s` | Поиск через fd в текущей папке |
| `S` | Поиск через fd с нуля |

## 👁️ Просмотр
| Клавиша | Что делает |
|---------|-----------|
| `Enter` / `o` | Открыть файл |
| `O` | Открыть в другой программе |
| `i` | Предпросмотр во весь экран |
| `Tab` | Показать/скрыть превью |

## 📑 Вкладки
| Клавиша | Что делает |
|---------|-----------|
| `t` | Новая вкладка |
| `[` / `]` | Предыдущая / следующая вкладка |
| `1-9` | Перейти на вкладку N |
| `W` | Закрыть вкладку |

## ⚡ Разное
| Клавиша | Что делает |
|---------|-----------|
| `q` | Выйти |
| `Q` | Выйти + cd в текущую папку |
| `.` | Показать скрытые файлы |
| `z` | Прыгнуть через zoxide |
| `Z` | Перейти через fzf |
| `c m` | chmod (права доступа) |
| `!` | Открыть shell в текущей папке |
| `w` | Показать задачи (Tasks) |
| `?` | Показать все хоткеи |

## ⚙️ Конфигурации окружения (Noctalia / Niri Setup)

Мой кастомный сетап на базе горизонтального Wayland-композитора **Niri** и графической оболочки **Noctalia Shell v4.7.7**.

* 💻 **Терминал:** [Kitty Configuration](./kitty/kitty.conf) — графическое ускорение, кастомные шрифты Outfit.
* 🌀 **Композитор:** [Niri Configuration](./niri/config.kdl) — бесконечная горизонтальная лента, маппинги окон.
* 🚀 **Лаунчер:** [Vicinae TOML](./vicinae/config.toml) — тема Noctalia, фикс Twemoji.
* ⌨️ **Редактор:** [LazyVim Setup](./nvim/) — легковесные LSP-серверы через Mason (`pyright`, `basedpyright`).

## 📶 Дополнительные материалы к видео по Wi-Fi

Ссылки на проверенный бесплатный софт из моего гайда по разгону домашней сети:

* 📱 **Android:** [Wi-Fi Analyzer (Google Play)](https://play.google.com/store/apps/details?id=com.vrem.wifianalyzer) — опенсорсный сканер частот без рекламы.
* 🪟 **Windows:** [Ubiquiti WiFiman](https://ui.com) — наглядные графики интерференции сетей.
* 🐧 **Linux:** `sudo iwlist scan` или утилита `LinSSID` для сканирования окружения прямо из Kitty.
