# 📦 Archive

Здесь хранятся конфиги, которые я больше не использую, но не хочу терять.

## waybar-arch/
Конфигурация Waybar с Arch Linux + niri (2026).
Особенности:
- `niri_lang.py` — скрипт-индикатор раскладки клавиатуры для niri через `niri msg keyboard-layouts`
- Стилизация под тёмную тему
- Модули для управления через niri

Восстановить активным:
```bash
cp -r waybar-arch ~/.config/waybar
```
